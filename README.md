# Pagefold

Дневник для iPhone, устроенный как переплётная мастерская: полка с тетрадями, внутри каждой — вертикальная лента страниц-записей, а в редакторе рядом с текстом живёт ИИ-помощник на Claude API.

Приложение полностью офлайновое: записи лежат в локальном SwiftData-хранилище, наружу уходят только те запросы, которые вы сами отправляете ИИ-помощнику.

## Что умеет

**Полка.** Тетради с тканевыми обложками и резинкой, перестановка перетаскиванием, раздел «Продолжить» с последними записями. Поиск идёт и по названиям тетрадей, и по содержимому записей: найденная страница открывается сразу, а её тетрадь помечается ляссе-закладкой.

**Лента.** Вертикальная лента карточек-страниц с зумом у центра экрана, рейка-насечки слева для быстрого перехода к нужной записи, «призрачная страница» в конце вместо плавающей кнопки, лист «Все записи» с поиском и сменой порядка.

**Редактор.** Текст лежит на настоящей «странице» с маргиналией и номером, к записи можно приложить фотографии (полноэкранный просмотр с листанием и зумом) и выбрать обложку. Автосохранение с отметкой «сохранено»; брошенные пустые черновики удаляются сами.

**ИИ-панель.** Чипсы-действия с разными целями: дописать текст, переписать выделенное, придумать заголовок. Ответ стримится по мере генерации, вставку можно отменить. Запрос можно надиктовать голосом.

## Стек

- SwiftUI + SwiftData, iOS 17+, только iPhone, портретная ориентация
- Проект генерируется [XcodeGen](https://github.com/yonaskolb/XcodeGen) из `project.yml` — сам `.xcodeproj` не версионируется
- Claude API напрямую по HTTP (официального Swift SDK нет): Messages API, стриминг SSE, модель `claude-opus-5`
- Ключ API хранится в Keychain и вводится в настройках приложения — в коде и сборке его нет
- Диктовка — `SFSpeechRecognizer` (в симуляторе не работает, проверять на устройстве)

## Сборка

```bash
brew install xcodegen                       # если ещё не стоит
cp Config/Local.xcconfig.example Config/Local.xcconfig
# впишите свой DEVELOPMENT_TEAM в Config/Local.xcconfig
xcodegen generate
open Pagefold.xcodeproj
```

Для запуска в симуляторе Team ID не нужен — файл `Config/Local.xcconfig` можно оставить с заглушкой. Он требуется только для установки на устройство.

После первого запуска откройте настройки в приложении и вставьте ключ Anthropic API (`sk-ant-…`) — без него работает всё, кроме ИИ-панели.

## Структура

```
Pagefold/
├── Models/        SwiftData-модели: Folder, Card
├── Views/         Полка, лента, редактор, ИИ-панель, настройки
├── Services/      Клиент Claude API, Keychain, распознавание речи
└── Support/       Дизайн-система (Theme, Components), форматтеры, работа с фото
```

Дизайн-система собрана в `Support/Theme.swift` (цвета, типографика на семантических стилях ради Dynamic Type, отступы, хаптика) и `Support/Components.swift` (бумажное зерно, разлиновка, фирменный загнутый уголок `DogEarRect`, кнопки, пустые состояния, тосты).
